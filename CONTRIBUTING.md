# Contributing to Splat Studio

Thanks for helping improve Splat Studio.

Before opening a pull request:

1. Keep machine-specific paths out of source code.
2. Do not commit projects, model caches, runtime environments or generated
   reconstruction data.
3. Test changes on a clean project.
4. Preserve third-party copyright/license notices.
5. Keep optional AI failures non-destructive where possible.
6. Document new dependencies and any license restrictions.

Useful issue reports include:

- macOS version
- Apple Silicon chip
- Splat Studio version/commit
- reconstruction profile
- source type (video/photos)
- relevant console output

Do not upload private source photos/videos unless you are comfortable making
them public.
