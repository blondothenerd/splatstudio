# Splat Studio v1.0.0

Created by **blondothenerd**.

First public release.

## Highlights

- Video and photo Gaussian Splat reconstruction
- COLMAP camera solving and automatic camera rescue
- Native Apple Silicon MLX / C++ / Metal training
- AI-assisted depth/masking options
- Training snapshots and resume
- Automatic unattended retry
- Live training previews
- Reconstruction profiles
- SuperSplat review/edit/view integration
- Recommended viewpoints
- Automatic scene orientation correction
- Project management
- Custom themes

## Platform

Initial release targets Apple Silicon macOS systems with the full Xcode Metal
toolchain.
